Подключим Spotify

Один раз настройте подключение — затем библиотека будет доступна при каждом запуске.

  1. 01
    Откройте Spotify Developer Dashboard ↗ и создайте приложение. Выберите Web API и Web Playback SDK.
  2. 02
    В настройках приложения добавьте Redirect URI:
    http://127.0.0.1:43821/callback
  3. 03
    Скопируйте Client ID и вставьте ниже. Client Secret не нужен. Если вход выполняет другой аккаунт, добавьте его в User Management приложения Spotify.

Нужны Spotify Premium и доступ к Spotify через интернет. Вход проходит на сайте Spotify. Токены входа защищены средствами Windows. Библиотека хранится на этом компьютере.
