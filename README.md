# Luma Music

Музыкальный плеер для Windows с интерфейсом Liquid Glass, светлой и тёмной
темами, русским и английским языками. Текущая версия — **1.14**.

## Скачать

Откройте **Releases** справа на странице репозитория и выберите **Luma Music 1.14**.
Скачайте `LumaMusic-1.14-Windows.zip`, распакуйте и запустите
`LumaMusic-1.14.exe`. Перед запуском закройте прежнюю версию приложения.

Требуются Windows 10/11 x64, .NET Framework 4.8 и Microsoft Edge WebView2 Runtime.
Chrome, Python и Node.js для использования готовой программы не нужны.

## Возможности

- Spotify Premium: подключение аккаунта, импорт библиотеки, поиск и воспроизведение.
- SoundCloud: поиск внутри Luma, локальная библиотека и воспроизведение через
  официальный Widget; без синхронизации аккаунта и без API-ключа SoundCloud.
- Общие любимые и локальные плейлисты с треками из обоих сервисов.
- Раздельные поиск и «Моя волна» для Spotify и SoundCloud.
- Страницы артистов, популярные треки и обложки.
- Локальные аудиофайлы, большой плеер, тексты LRCLIB/Genius и импорт LRC.
- Передача названия, исполнителя и обложки в медиасессию Windows для совместимых
  приложений, включая Lively Wallpaper.

Воспроизведение Spotify требует Premium и своего Client ID из Spotify Developer
Dashboard. Скачивания аудио Spotify в Luma нет. Доступность SoundCloud зависит от
ограничений сервиса и автора. Genius может вернуть обычный текст без синхронизации.

## Сборка из исходников

Откройте PowerShell в папке репозитория:

```powershell
.\build.ps1 -OutputFile LumaMusic-1.14.exe
```

Результат: `dist\LumaMusic-1.14.exe`. Используется компилятор .NET Framework,
поставляемый с Windows. Библиотеки WebView2 и их лицензия находятся в `vendor/webview2`.

## Проверки

Валидация 1.14: **106 автоматических проверок прошли**, включая защищённый
локальный сервер. Проверены задержки ответов, быстрые переключения источников,
смешанные очереди, очередь из 121 трека, локальный тихий WAV и настройки в двух
темах и на двух языках при размере окна 900×700.

Для запуска полного набора нужен Node.js 18+ и отдельный тестовый экземпляр Luma:

```powershell
.\dist\LumaMusic-1.14.exe --no-window --data-dir "$PWD\.test-data" --port 43904
```

В другом окне PowerShell:

```powershell
$env:LUMA_TEST_ROOT = "$PWD\.test-data"
node --test (Get-ChildItem .\tests\*.test.cjs).FullName
```

Тесты используют отдельную библиотеку; не запускайте их на своей основной папке
данных. Проверки интерфейса описаны в [tests/browser/README.md](tests/browser/README.md).
Результаты и границы проверки — в [AUDIT-1.14.md](AUDIT-1.14.md).
Spotify и SoundCloud в проверках интерфейса имитируются; реальное воспроизведение
этих сервисов в WebView2 от начала до конца пока не подтверждено.

## Структура и данные

`Program.cs` — локальный сервер; `MainWindow.cs` и `WindowChrome.cs` — окно Windows;
`NativeMediaSession.cs` — медиасессия; `web/` — интерфейс и управление плеерами;
`tests/` — проверки; `docs/USER-GUIDE-RU.txt` — инструкция по настройке.

Данные пользователя сохраняются в `%LOCALAPPDATA%\LumaMusic`. Токены Spotify
защищены Windows DPAPI. Пользовательские библиотеки, токены и профиль WebView2
не входят в исходники или архив релиза.

Luma — независимое приложение, не официальный клиент Spotify или SoundCloud.
